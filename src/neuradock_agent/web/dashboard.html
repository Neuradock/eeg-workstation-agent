What does 1.00× mean?

The chart shows posterior Alpha-band (8–13 Hz) power divided by a rolling baseline. A value of 1.18× means 18% more power than that reference, not 18% more relaxation.

The reference is the median log Alpha power of up to 600 clean analysis windows, including the current valid window. At least three clean windows are required. It changes as the session continues; it is not a fixed pre-training calibration.

Each historical point uses its own rolling baseline. Signal-quality warnings, stale data and disconnected devices disable feedback. The ring fills over 0–1.5× and caps at its ends; the number and chart retain the actual ratio.

Keep the same eye state when comparing conditions. This is a signal feature, not a diagnosis, relaxation score or evidence of treatment.
