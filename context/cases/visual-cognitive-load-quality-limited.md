# Reference Case: Quality-Limited Visual Cognitive Load

Case type: reviewed local workflow example

The public `open_closed_eye2.txt` example, rerun with hardware profile 1.1,
produced 49 overlapping windows, but only 10 met the 80% clean-sample
requirement. Thirty-nine windows were excluded. The load-label plot therefore
appeared discontinuous.

Appropriate interpretation:

- Continue explaining the 10 valid windows.
- Put the low-retention and excluded-window warning first.
- State that temporal coverage is sparse and thresholds may be unstable.
- Treat blank plot regions as unavailable estimates, not zero load.
- Do not interpolate through excluded windows.

The low, medium, and high counts describe only valid windows in that recording.
They do not establish absolute cognitive load.

Source:

- `open_closed_eye2.txt` rerun with hardware profile 1.1
