# Reference Case: Eyes Open and Eyes Closed

Case type: public NeuraDock example

The public `open_closed_eye2.txt` example alternates eyes-open and eyes-closed
conditions. The expected research pattern is stronger posterior 8-13 Hz Alpha
during eyes closed and Alpha suppression after opening the eyes.

Use this as background for Alpha interpretation, not as proof that every Alpha
change identifies eye state. The current Agent does not expose the old
eyes-open/eyes-closed classifier as a reviewed CLI workflow.
