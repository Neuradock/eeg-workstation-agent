# Reference Case: Rest and Reading Task

Case type: public NeuraDock example

The public sample set includes a relaxed resting recording and a high-load text
reading recording. The expected example pattern is lower posterior Alpha power
during the reading task, commonly described as Alpha event-related
desynchronization.

This is a reference paradigm, not a universal rule. Differences can also be
affected by signal quality, eye state, posture, electrode contact, timing, and
protocol design. The current Visual Cognitive Load workflow labels windows
within one recording and must not be presented as a validated cross-session
rest-versus-task classifier.
